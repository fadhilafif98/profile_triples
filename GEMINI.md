# tripleS Fan Directory — Engineering & Data Architecture Guide (`GEMINI.md`)

Panduan teknis resmi untuk pengembangan, arsitektur data, penambahan konten, dan standar desain website **tripleS Profile & Fan Directory** (`profile-triples.vercel.app`).

---

## 1. Arsitektur Data (*Single Source of Truth*)

Proyek ini mengadopsi arsitektur **1 File per Entitas (JSON Modular)** untuk memastikan integritas data, kemudahan pemeliharaan, dan performa tinggi tanpa dependensi database eksternal.

### Struktur Direktori Data:
```
src/
├── data/
│   ├── members/       # 24 file JSON member (s01-yoon-seo-yeon.json ... s24-jiyeon.json)
│   ├── albums/        # 18 file JSON album (01-access.json ... 18-love-and-pop-pt1.json)
│   └── sub-units/     # 15 file JSON sub-unit (01-acid-angel-from-asia.json ... 15-zenith.json)
├── lib/               # Data Loader terpusat (TypeScript)
│   ├── members.ts     # getAllMembers(), getMemberBySlug(), getMemberById()
│   ├── albums.ts      # getAllAlbums(), getAlbumById(), latest releases
│   └── sub-units.ts   # getAllSubUnits(), getSubUnitBySlug(), getSubUnitsByCategory()
└── types/             # Kontrak Interface TypeScript
    ├── member.ts      # Interface Member
    ├── album.ts       # Interface Album
    └── sub-unit.ts    # Interface SubUnit
```

## 2. Skema Entitas & Konvensi Penamaan

### A. Member (`src/types/member.ts`)
* **`name`**: Nama panggung resmi tunggal / nickname (misal: `SeoYeon`, `HyeRin`, `JiWoo`, `Kaede`, `SeoAh`). Ini yang tampil di kartu grid, judul utama, dan badge.
* **`birthName`**: Nama lengkap / nama lahir asli (misal: `Yoon Seo-yeon`, `Yamada Kaede`, `Jeong Hae-rin`).
* **`hangul`**: Hangul untuk nama panggung (misal: `서연`, `혜린`, `카에데`).
* **`birthNameHangul`**: Hangul untuk nama lahir lengkap (misal: `윤서연`, `야마다 카에데`, `정해린`).
* **`nativeName`**: Aksara asli untuk member internasional (Jepang: Kanji, Tiongkok: Hanzi, Thailand: Thai).
* **`slug`**: Identifier URL unik (misal: `yoon-seo-yeon`, `seoah`, `kaede`).
* **`representativeEmoji`**: Format: `[Emoji] ([Label])` contoh `🐶 (Puppy) / 🐹 (Hamster)`.

### B. Album (`src/types/album.ts`)
* **`id`**: Identifier album (misal: `18-love-and-pop-pt1` atau `assemble24`).
* **`title`**: Judul resmi album.
* **`type`**: `"Studio Album" | "Mini Album" | "Single Album" | "Digital Single" | "Japanese EP" | "Japanese Single"`.
* **`unit`**: Unit yang merilis (misal: `tripleS (OT24 Full Group)` atau `Acid Angel from Asia`).

* **`cover`**: Lokasi file di folder `public/album/` (misal: `/album/18_LOVE_AND_POP_PT1.jpg`).

## 3. Langkah-Langkah Menambah & Mengupdate Data

### A. Cara Menambah Album Baru:
1. Simpan gambar sampul di `public/album/{nomor}_{JUDUL}.jpg`.
2. Buat file baru `src/data/albums/{nomor}-{slug}.json` dengan skema `Album`.
3. Buka [src/lib/albums.ts](file:///Users/macair/Project/Github/profile_triples/src/lib/albums.ts):
   * Import file JSON baru: `import aXX from "@/data/albums/{nomor}-{slug}.json"`
   * Masukkan ke dalam array `albumsList`.
   * Album terbaru otomatis muncul di timeline discography dan Featured Release landing page.

### B. Cara Mengupdate Data Member:
1. Edit file bersangkutan di `src/data/members/s{ID}-{slug}.json`.
2. Jika ada perubahan nama/panggung:
   * Perbarui `name` dengan nama panggung (CamelCase).
   * Perbarui `birthName` dengan nama lengkap.
   * Pastikan `hangul` dan `birthNameHangul` sesuai.
3. Simpan file. HMR (*Hot Module Replacement*) langsung memperbarui UI di browser.

### C. Cara Menambah Sub-Unit (Dimension) Baru:
1. Simpan foto unit di `public/sub-units/sub_unit_{nama}.jpg`.
2. Buat file baru `src/data/sub-units/{nomor}-{slug}.json`.
3. Buka [src/lib/sub-units.ts](file:///Users/macair/Project/Github/profile_triples/src/lib/sub-units.ts):
   * Import file JSON: `import uXX from "@/data/sub-units/{nomor}-{slug}.json"`
   * Tambahkan ke array `subUnits`.

## 4. Standar Desain & Awwwards-Level UI/UX Lock

> **DESIGN LOCK**: Standar visual ini berstatus **STRICT & LOCKED**. Seluruh agen AI dan developer dilarang menyimpang ke template LLM default (AI slop) seperti kartu SaaS 3-kolom generik, purple neon glow, bracket mono tracking berlebihan, atau em-dash.

### A. Core Dials & Tri-Skill Design Protocol:
* **`DESIGN_VARIANCE: 9`** (Komposisi editorial asimetris, dinamika whitespace percaya diri, ritme visual bervariasi antar section).
* **`MOTION_INTENSITY: 8`** (GSAP + ScrollTrigger kinetic typography & pinned storytelling, Motion spring physics pada micro-interactions UI).
* **`VISUAL_DENSITY: 3`** (Airy, breathing room premium, tidak ada kartu data yang saling berdesakan atau data-dump table).

#### Tri-Skill Design Synergy Architecture:
Proyek ini mengintegrasikan sinergi tiga skill desain frontend (`.agents/skills/`):
1. **`design-taste-frontend`**: Anti-slop invariants, *The Lila Rule* (kontras tinta karbon murni di Light Mode), batasan dial visual, audit-first pada redesign, dan pre-flight check terhadap AI tells.
2. **`frontend-design`**: Panduan tipografi editorial berkekuatan tinggi, komposisi visual majalah fashion/K-Pop, dan penataan tata letak non-template.
3. **`impeccable` (`pbakaus/impeccable`)**: Standar craft kelas direktur desain (*out-of-distribution craft*), *craft-floor* quality floor, hierarki visual ketat, mikro-interaksi taktil, adaptasi responsif mobile-first, dan eksekusi tanpa kompromi (*zero shortcuts*).

> **MANDATORY DESIGN LOGGING RULE**:
> Setiap kali mendesain, memoles, atau merombak antarmuka frontend, AI agent dan developer **WAJIB mencatat seluruh keputusan visual, perubahan teknis, dan rationale anti-slop ke dalam Log Riwayat Perubahan Signifikan di `GEMINI.md`**.

* **Display & Headline Utama (`--font-display`)**:
  * Font: `Syne` (Google Font) / `Pretendard` (Hangul fallback).

  * Font: `Manrope` (Google Font).
  * Karakter: Clean geometric neo-grotesque, ultra-legible, modern agency standard (1:1 font utama LxL Creative). Max line-length: `65ch`.
* **Technical Metadata & S-Number (`--font-mono`)**:
  * Font: `JetBrains Mono` (`font-mono`) tanpa bracket pembungkus (`S1`, `2026.08`, bukan `[ S1 ]`).
* **BANNED TYPOGRAPHY**:
  * Dilarang menggunakan `Inter`, `Fraunces`, atau serif generik tanpa motivasi brand.

### D. LxL Creative Motion & Micro-Interactions:
* **Interactive Underline Draw (`.nav-draw-link`)**:
  * Seluruh link navbar dan tab menggunakan garis bawah `#D4FF00` yang tumbuh dari kiri ke kanan saat hover (`scaleX(0)` → `scaleX(1)`).
* **Tactile Magnetic Buttons (`.btn-magnetic`)**:
  * Tombol CTA mengintegrasikan micro-movement di mana panah bergeser 45° (`.btn-arrow translate(3px, -3px)`) dengan spring physics saat hover.
* **Spotlight Bento Cards (`.spotlight-card`)**:
  * Menggunakan surface adaptif (light: `#FFFFFF` dengan soft zinc border; dark: `#0D0D12` dengan bevel `inset 0 1px 0 rgba(255,255,255,0.12)`).
* **Authentic K-Pop Editorial 24-Member Hero (`<HeroSection />`)**:
  * Format hero mengadopsi standar **Anti-Slop Editorial K-Pop Poster**:
    1. **Lower-Third Anchor Layout**: Tipografi monumental `tripleS` ditempatkan di sepertiga bawah (`justify-end`), menjaga seluruh wajah 24 member di foto atas tetap bersih tanpa terhalang huruf.
    2. **Tanpa AI-Slop Gimmicks**: Dilarang memasang widget template generik (jam digital KST di pojok, animasi mouse capsule "scroll to explore", atau cursive script font yang ditumpuk paksa).
    3. **Fluid Optical Typography Scale**: Menggunakan fluid scale seimbang (`text-4xl xs:text-5xl sm:text-6xl md:text-7xl lg:text-8xl xl:text-[6.5rem] 2xl:text-[7.5rem]`) dengan kerning optik `tracking-[-0.04em]` dan `leading-[0.9] sm:leading-[0.88]`.
    4. **Accessible Semantics & Contrast**:
       - `aria-labelledby="hero-main-heading"` dan hidden screen-reader description (`.sr-only`) membacakan ke-24 nama member secara utuh.
       - Contrast well gradient 42vh–48vh menjamin rasio kontras > 16:1 (WCAG AAA) tanpa menutupi detail pakaian member di baris bawah.
       - Navigasi footer hero memiliki visible keyboard focus ring (`focus-visible:ring-2 focus-visible:ring-[#D4FF00] focus-visible:ring-offset-2`).
    5. **Mobile-First Focal Point & Safe Area**:
       - Focal point foto terkunci di `object-[center_28%]` agar wajah member tetap utuh di layar rasio vertikal 9:16 / 19.5:9.
       - Padding bawah adaptif (`pb-6 sm:pb-12`) agar tidak menabrak bar browser mobile (Safari/Chrome).
       - Mouse parallax otomatis dinonaktifkan pada reduced motion (`useReducedMotion()`) dan layar sentuh (<1024px).
* **GSAP + ScrollTrigger**:
  * Parallax scrub halus pada framed group photo dan staggered line reveal pada headline hero.
  * Wajib diisolasi di komponen Client leaf (`"use client"`) menggunakan `gsap.context()` di dalam `useEffect`, dan wajib menyertakan `ctx.revert()` pada cleanup.

### F. Standar Halaman Profil Member (*Zero-Scroll Above-the-Fold*):
* Foto profil resmi, nama panggung, nomor S, badge emoji, MBTI, dan tabel spesifikasi terintegrasi langsung di viewport atas tanpa perlu scrolling banner kosong.
* **Tabel Spesifikasi**:
  1. `Stage Name (예명 / 활동명)`: Nama panggung + Hangul.
  2. `Birth Name (본명)`: Nama lahir lengkap + Hangul + Native Script.
  3. `Birthday (생년월일)`: Format tanggal + umur internasional.

   * Komponen interaktif yang bergantung pada status browser (`window`, `localStorage`, atau `scroll`) wajib menggunakan guard `mounted` state atau `suppressHydrationWarning`.

   * Semua data loader wajib memiliki *strict return type*.
